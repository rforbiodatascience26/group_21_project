Finally, we are making a scatterplot colored by subtype to help us answer the project question do tumors belonging to the same subtype share proteins? If the subtypes properly separate, then we could argue that proteins seem to distinguish the subtypes; whereas if they’re all scattered, then the proteins aren’t enough to do so. Also, the groups that are placed closer to one another will have similar profiles.

K-means

Now, we will carry out k-means clustering (with and without PAM50) as a way to further support the answer we obtain after Principal Component Analysis. Right now, we have the PCA scatterplot, which helps us visually observe whether the subtypes are separated properly given their protein profiles, but a K-means will help us back up any conclusion with more numbers. Also, we will carry out different iterates with different number of clusters to compare their silhouette scores. Once again, this is based on a GeeksForGeeks tutorial.

Slight preprocessing to split the protein columns (with and without PAM50).

pam50_ids <- read_csv("../data/_raw/PAM50_proteins.csv", show_col_types = FALSE) |> 
  pull(RefSeqProteinID)

pam50_only <- pca_wide |> 
  select(any_of(pam50_ids))

no_pam50 <- pca_wide |>

Cluster number comparison with silhouette scores.

cluster_scores <- function(mat, k_values=2:8){
  d <- dist(mat)
  tibble(k=k_values) |> 
    mutate(km = map(k, \(k) kmeans(mat, centers = k, nstart=25)),
           sil = map_dbl(km, \(m) mean(silhouette(m$cluster, d)[, 3]))) |> 
             select(k, sil)
}
set.seed(42) #ensuring reproducibility
scores <- bind_rows(cluster_scores(pam50_only) |> 
                      mutate(set="PAM50 only"),
                    cluster_scores(no_pam50) |> 
                      mutate(set="No PAM50")
)
scores |> 
  ggplot(aes(x=k, y = sil)) +
  geom_line() +
  geom_point() +
  facet_wrap(~ set)+
  labs(x="Number of clusters (k)",
       y = "Silhouette score") +
  theme_minimal()
